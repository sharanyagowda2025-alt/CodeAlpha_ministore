# 🛍️ MiniStore – Full Stack E-Commerce Website

MiniStore is a modern and interactive full-stack e-commerce website developed using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB. It provides a user-friendly shopping experience with product browsing, shopping cart management, user authentication, and checkout functionality.

## ✨ Features

- 🛒 Interactive shopping cart
- 🔍 Product search functionality
- 📂 Category-based product filtering
- 🖼️ Product details modal
- 👤 User registration and login
- 🔐 Secure password hashing using bcrypt
- 💳 Checkout functionality
- 📦 Order management
- 🔔 Toast notifications
- 📱 Responsive and modern user interface
- 🗄️ MongoDB database integration

## 🛠️ Technologies Used

### Frontend

### Backend

## 🚀 Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/sharanyagowda2025-alt/CodeAlpha_ministore.git
```

### 2. Navigate to the Project Folder

```bash
cd CodeAlpha_ministore
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure MongoDB

Make sure MongoDB is running locally or configure your MongoDB Atlas connection.

Set your MongoDB connection string in the server configuration using an environment variable or your local setup.

Example:

```env
MONGODB_URI=mongodb://127.0.0.1:27017/ministore
```

Do not commit your `.env` file or expose database credentials.

### 5. Start the Application

```bash
npm start
```

For development:

```bash
npm run dev
```

### 6. Open in Browser

Visit:

```text
http://localhost:3000
```
